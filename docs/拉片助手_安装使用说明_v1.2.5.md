# 拉片助手（PianAssistant）v1.2.5 安装使用说明

> 配套安装包：`PianAssistant_Setup_v1.2.5.exe`（约 145 MB）
> 适用对象：所有用户；从 v1.0.0 升级的用户请重点阅读**第四节「从 v1.0.0 升级」**。

---

## 一、版本与系统要求

| 项目 | 要求 |
|------|------|
| 版本 | v1.2.5 |
| 操作系统 | Windows 10 / Windows 11（64 位） |
| 磁盘空间 | 安装约 165 MB + 数据目录（按视频时长与截图量增长） |
| **预装环境** | **无**——.NET 10 运行时、VLC 解码库、ffmpeg 已全部打包进安装包，换电脑即装即用 |

---

## 二、安装步骤

1. 双击 `PianAssistant_Setup_v1.2.5.exe` 启动安装向导（简体中文界面）。
2. 欢迎页 → 「下一步」。
3. **选择安装位置**（默认 `C:\Users\<你的用户名>\AppData\Local\Programs\PianAssistant`），建议保持默认；也可改到其他盘。
4. **附加任务**：勾选「创建桌面快捷方式」（可选）→ 「下一步」。
5. 点「安装」，等待进度条完成。
6. 安装完成 → 勾选「运行 拉片助手」→ 「完成」。

> **提示**：本安装包**无需管理员权限**。若 Windows SmartScreen 弹出「已保护你的电脑」，点「更多信息」→「仍要运行」即可。

---

## 三、启动与卸载

- **启动**：开始菜单 →「拉片助手」，或双击桌面快捷方式。
- **卸载**：开始菜单 →「拉片助手」→「卸载 拉片助手」；也可在「设置 → 应用 → 已安装的应用」中找到「拉片助手」卸载。
- 卸载**不会删除**你的笔记数据（截图、片段、数据库都在「数据根目录」，见第八节）。

---

## 四、从 v1.0.0 升级

### 4.1 升级方式

- **直接运行新安装包覆盖安装**即可，无需卸载旧版；安装位置、数据根目录、全部笔记数据（截图 / 片段 / 裁切点 / 勾选标记 / 播放进度）**自动兼容保留**。
- 升级后首次打开视频，上次的拉片记录（含黄色标记带）会自动恢复。

### 4.2 v1.0.0 → v1.2.5 变更总览

| 版本 | 变更 | 对你的影响 |
|------|------|-----------|
| v1.1.0 | **时间轴交互重定义 + UI 设计统一**：播放头所在片段自动选中高亮（白色）；C 键在播放头处添加裁切点分段；标记片段变黄色带；裁切点红 / 截图点绿 / 片段黄色彩规范统一 | 时间轴操作更直观，详见第六节 |
| v1.1.1 | 修复：无裁切点时片段选中 / 标记不可用 | 打开视频即可直接标记整片 |
| v1.1.2 | 修复：打开带裁切点的视频崩溃 | 稳定性修复 |
| v1.1.3 | **默认快捷键调整**：截图 `S` → `X`；新增标记片段 `V` | 详见 4.3 注意事项 |
| v1.2.0 | **导入数据自动重建缺失截图**：导入的表格数据里截图行只有时间码没有图片文件时，自动用 ffmpeg 从源视频按时间码重新截取 | 换电脑 / 只分享数据也能还原截图，详见第五节 |
| v1.2.1 | 确认空格 = 播放/暂停（默认即生效） | 无感知 |
| v1.2.2 | 修复：倍速播放时后退回弹；导出片段起止点与时长偏差 | 倍速下后退/快进更丝滑；**导出片段时长更准**（流复制模式起点仍有关键帧对齐的固有偏差，需帧级精确请用重编码导出） |
| v1.2.3 | 修复：倍速播放时截图不精确（最高可偏 10 帧） | 倍速下截图与按下瞬间画面帧对齐 |

### 4.3 升级注意事项

1. **快捷键变化**：截图改为 `X`（原 `S`），标记片段为 `V`。如果你曾在设置里**自定义过**快捷键，自定义值优先——需要在 ⚙「设置」→「快捷键」中手动调整，或点「全部重置」恢复新默认。
2. **数据完全兼容**：旧版本的截图、片段、裁切点、勾选标记、播放进度全部保留，无需迁移。

## 五、导入 / 导出拉片数据

- **导出数据**（📋 按钮）：把当前视频的裁切点、片段、截图清单、勾选标记导出为 Excel（.xlsx，默认）或 CSV，可用 Excel 直接人工编辑。
- **导入数据**（📥 按钮）：导入人工编辑过的 .xlsx / .csv **覆盖**当前视频的笔记数据（导入前有确认提示）。
  - **v1.2.0 起**：截图行只有时间码、没有图片文件时，会**自动从源视频按时间码重新截取**（后台执行，完成后右下角提示「重建缺失截图 N/total」）——换电脑或只分享数据文件也能完整还原截图。
  - 图片文件仍存在时直接使用原文件，不重复截图。

## 六、时间轴交互（v1.1.0 重定义）

| 操作 | 行为 |
|------|------|
| 播放头移动 | 所在片段**自动选中**并白色高亮跟随 |
| `C` 添加裁切点 | 在播放头当前位置把片段一分为二 |
| `V` 标记片段 | 标记 / 取消标记当前选中片段，片段显示**黄色带**，与「拉片笔记」面板的 ☑ 勾选**双向同步**（参与批量导出、「仅标记」筛选与自动保存） |
| `X` 截图 | 时间轴添加绿色截图标记点，后台 ffmpeg 从源视频按当前帧时间码抽帧（倍速播放下也能精确对齐当前画面帧） |
| 滚轮 | 时间轴缩放（0.5× ~ 50×） |

> 颜色规范：裁切点红 ▼、截图点绿 ■、已标记片段黄带、入出点蓝、播放头白。

## 七、核心快捷键速查

| 功能 | 快捷键 |
|------|--------|
| 播放 / 暂停 | `Space` |
| 上一帧 / 下一帧 | `←` / `→` |
| 后退 / 前进 1 秒 | `Shift+←` / `Shift+→` |
| 后退 / 前进 10 秒 | `Ctrl+←` / `Ctrl+→` |
| 跳到开头 / 结尾 | `Home` / `End` |
| 标记入点 / 出点 | `I` / `O` |
| 添加裁切点（在播放头处分段） | `C` |
| **标记 / 取消标记当前片段**（黄带，v1.1.0 新增） | `V` |
| **截图**（时间轴标记 + 缩略图进笔记） | `X` |
| 截取片段（入出点之间） | `Ctrl+Shift+E` |
| 导出当前选中片段 | `Ctrl+E` |
| 清空全部标记（裁切点 + 截图） | `Ctrl+Shift+C` |
| 撤销上一个裁切点 | `Backspace` |
| 全屏 / 退出全屏 | `F` / `Esc` |
| 倍速增加 / 减少（0.25× ~ 8×） | `+` / `-` |
| 静音切换 | `M` |
| 循环播放切换 | `L` |

> 所有快捷键可在 ⚙「设置」→「快捷键」中自定义；自定义值优先于默认值。

## 八、数据存储与迁移

- 顶栏 ⚙「设置」→「输出设置」→「数据根目录」：截图、片段、笔记数据库、全局配置**统一存放于此**（自动创建 `screenshots\`、`clips\` 子文件夹）。
- **迁移到新电脑**：拷贝安装目录（或直接用安装包重装）+ 拷贝数据根目录 → 新机设置同一根目录即可，无需其它配置。

## 九、常见问题

**Q1：升级后按 S 不能截图了？**
截图已改 `X`（v1.1.3）。若自定义过快捷键，到设置 → 快捷键中调整或「全部重置」。

**Q2：倍速播放时后退会回弹吗？**
v1.2.2 起已修复：seek 后短暂抑制旧位置帧上报，倍速下后退 / 快进不回弹、长按步进连贯。

**Q3：导入数据后截图怎么只有记录没有图片？**
v1.2.0 起会自动按时间码从源视频重新截取，请确保导入前已打开对应的源视频；完成后看右下角提示。

**Q4：导出的片段时长和软件里显示的对不上？**
v1.2.2 已修复时间基准问题。若使用「快速导出（流复制）」，起点仍会向前对齐到最近关键帧（最多差 1 个 GOP），需要帧级精确请勾选重编码导出。

**Q5：安装时提示「已保护你的电脑」？**
SmartScreen 对未签名程序的常规提示，点「更多信息」→「仍要运行」。
