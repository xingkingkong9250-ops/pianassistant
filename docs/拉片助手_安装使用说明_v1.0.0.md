# 拉片助手（PianAssistant）v1.0.0 安装使用说明

> 配套安装包：`PianAssistant_Setup_v1.0.0.exe`（约 143 MB）

---

## 一、版本与系统要求

| 项目 | 要求 |
|------|------|
| 版本 | v1.0.0 正式版 |
| 操作系统 | Windows 10 / Windows 11（64 位） |
| 磁盘空间 | 安装约 160 MB + 数据目录（按视频时长与截图量增长） |
| **预装环境** | **无**——.NET 10 运行时、VLC 解码库、ffmpeg 已全部打包进安装包，换电脑即装即用 |

---

## 二、安装步骤

1. 双击 `PianAssistant_Setup_v1.0.0.exe` 启动安装向导（简体中文界面）。
2. 欢迎页 → 「下一步」。
3. **选择安装位置**（默认 `C:\Users\<你的用户名>\AppData\Local\Programs\PianAssistant`），建议保持默认；也可改到其他盘。
4. **附加任务**：勾选「创建桌面快捷方式」（可选）→ 「下一步」。
5. 点「安装」，等待进度条完成。
6. 安装完成 → 勾选「运行 拉片助手」→ 「完成」。

> **提示**：本安装包**无需管理员权限**。若 Windows SmartScreen 弹出「已保护你的电脑」，点「更多信息」→「仍要运行」即可。

---

## 三、启动与卸载

- **启动**：开始菜单 →「拉片助手」，或双击桌面快捷方式。
- **卸载**：开始菜单 →「拉片助手」→「卸载 拉片助手」；也可在「设置 → 应用 → 已安装的应用」中找到「拉片助手」卸载。
- 卸载**不会删除**你的笔记数据（截图、片段、数据库都在「数据根目录」，见第七节）。

---

## 四、首次使用

1. **打开视频**：把视频文件拖进窗口，或点顶栏 📂「打开视频」按钮。
2. **设置数据根目录**（重要）：顶栏 ⚙「设置」→「输出设置」→「数据根目录」，选一个空间充足的磁盘路径。
   - 截图、片段、笔记数据库、全局配置**全部存到这里**，方便备份与迁移。
3. 回到主界面开始拉片。

---

## 五、核心快捷键速查

| 功能 | 快捷键 |
|------|--------|
| 播放 / 暂停 | `Space` |
| 上一帧 / 下一帧 | `←` / `→` |
| 后退 / 前进 1 秒 | `Shift+←` / `Shift+→` |
| 后退 / 前进 10 秒 | `Ctrl+←` / `Ctrl+→` |
| 跳到开头 / 结尾 | `Home` / `End` |
| 标记入点 / 出点 | `I` / `O` |
| 添加裁切点 | `C` |
| 截取片段（入出点之间） | `Ctrl+Shift+E` |
| 清空全部标记（裁切点 + 截图） | `Ctrl+Shift+C` |
| 撤销上一个裁切点 | `Backspace` |
| 截图（时间轴标记 + 自动生成缩略图） | `S` |
| 全屏 / 退出全屏 | `F` / `Esc` |
| 倍速增加 / 减少（0.25× ~ 8×） | `+` / `-` |
| 静音切换 | `M` |
| 循环播放切换 | `L` |

> 所有快捷键可在 ⚙「设置」→「快捷键」中自定义。

## 六、界面分区速览

- **R1 顶栏**：打开视频、播放列表开关、侧边栏开关、设置
- **R2 视频区 + 右侧「拉片笔记」面板**（默认展开，截图/片段/裁切点按时间混排）
- **R3 时间轴**：裁切点（红条 ✂）、截图标记（绿框 📷）、片段（黄框 🎬）
- **R4 底部控制栏**：时间码、倍速、音量、播放控制、截图/裁切点/清空按钮

---

## 七、数据存储与迁移

| 内容 | 位置 |
|------|------|
| 程序文件 | `%LocalAppData%\Programs\PianAssistant`（只读） |
| 数据根目录 | 设置中指定的路径，下含 `screenshots/`、`clips/`、数据库、`config.json` |

**换电脑迁移**：把整个「数据根目录」拷贝到新电脑，在新电脑的设置里把数据根目录指向该路径，所有笔记、截图、片段、配置即恢复。

## 八、常见问题

**Q：安装后启动没反应？**
A：首次启动需加载 VLC 解码引擎，稍等几秒。若被杀毒软件拦截，请将安装目录加入白名单。

**Q：倍速超过 4× 没声音？**
A：正常现象。LibVLC 音频时钟在 4× 以上会被钳制，程序自动在 4× 以上静音以保证画面流畅，降回 4× 以下自动恢复声音。

**Q：换电脑后笔记还在吗？**
A：笔记数据存放在你设置的「数据根目录」，不在安装目录。拷贝该目录到新电脑并重新指向即可（见第七节）。

**Q：安装包为什么这么大（140 MB+）？**
A：因为内置了 .NET 10 运行时、VLC 解码库和 ffmpeg，换电脑无需任何额外安装即可直接使用。

**Q：导入数据支持哪些格式？**
A：导出/导入支持 `.xlsx`（Excel）和 `.csv`，标记列为布尔值便于在 Excel 中直接编辑。
