## 块二：破坏性 / 异常测试

> 说明：以下部分测试会**故意破坏数据文件**，请在测试副本文档目录操作，避免影响正式数据。

### I. 断电 / 强杀进程

- [ ] 写设置后立刻强杀：修改设置并「保存并关闭」，紧接着用 `taskkill /IM PianAssistant.exe /F` 结束进程 → 重启后 `config.json` 完好（若写入中断，应由 `.backup` 原子恢复），设置不丢失。
- [ ] 导出中途强杀：批量导出片段过程中强杀进程 → 重启后检查临时文件被清理、已完成的片段文件可正常播放、无残留半成品被误判为成功。
- [ ] 截图写入中断：截图保存瞬间强杀 → 不产生 0 字节或损坏的图片被当作有效截图。

### J. 项目 / 数据文件损坏

- [ ] `.paproj` 截断：把某 `.paproj` 文件截断或写入乱码 → 用顶部 `📁 打开`（`W1-R1-19`）加载应友好报错（不崩溃），且原文件不被进一步破坏。
- [ ] 数据库损坏：手工破坏 `pianassistant.db` 文件头（如写入随机字节）→ 启动时应能恢复（重建/迁移）或给出友好提示，**不静默丢数据**、不闪退。
- [ ] 配置文件损坏：把 `config.json` 改成非法 JSON → 应用回退默认值启动；原文件不被覆盖（`.backup` 或原文件保留）。
- [ ] 配置备份恢复：删除主 `config.json`、保留 `config.json.backup` → 启动后应从备份恢复可用设置。

### K. 输入 / 依赖缺失

- [ ] 视频源缺失：播放列表中删除磁盘上的源文件后点击该项 → 友好提示，不崩溃；可继续操作其它项。
- [ ] 字幕缺失/损坏：拖入损坏字幕文件 → 不崩溃，加载失败有提示或静默忽略。
- [ ] ffmpeg 缺失：临时把 `Tools/ffmpeg/ffmpeg.exe`（发布目录 `tools\ffmpeg\`）改名 → 截图/截段/批量导出应给出**明确中文提示**，不闪退。
- [ ] ffmpeg 缺失（启动）：删除 `ffmpeg.exe` 后启动 → 弹出「缺少必要的依赖文件……请先运行 tools\download-ffmpeg.ps1 下载 ffmpeg」。

### L. 环境异常

- [ ] 磁盘空间不足：在小分区/满盘上导出 → 导出失败应提示，且**不产生半成品文件**（已写入部分应清理或标记失败）。
- [ ] 断网（离线）：全程断网启动/播放/截图/截段/笔记/批量 → 全部功能正常（应用不依赖网络）。
- [ ] 只读输出目录：把输出目录设为只读 → 导出失败有提示，不崩溃。
