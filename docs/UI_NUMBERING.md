# UI_NUMBERING — 拉片助手界面编号体系

本文件是**界面模块编号的唯一真源**。编号用于锁定控件位置：调整布局前先查编号，
调整后核对编号是否仍然指向同一功能。

## 编号规则

| 层级 | 格式 | 示例 | 说明 |
|---|---|---|---|
| 窗口 | `W{1..9}` | `W1` | 顶级窗口，按创建顺序编号 |
| 页签/区域组 | `W1-{A..D}` | `W1-A1` | 窗口内的页签或大区域 |
| 控件（三级） | `W1-{区域}-{NN}` | `W1-R2-05` | `NN` 为该区域内的两位序号 |

**铁律**

1. 编号全局唯一，定位到具体控件/字段。
2. 编号**不可随意修改**；功能修改后必须核对编号。
3. 功能删除则编号**跟随删除，永不复用**。
4. 新增功能**按顺序续编**，不得回填已删编号。

**窗口清单**

| 编号 | 窗口 | 文件 |
|---|---|---|
| W1 | 主窗口 | `Views/MainWindow.xaml` |
| W2 | 设置窗口 | `Views/SettingsWindow.xaml` |
| W3 | 截图画廊窗口 | `Views/GalleryWindow.xaml` |
| W4 | 批量操作窗口 | `Views/BatchWindow.xaml` |
| W5 | 标注编辑窗口 | `Views/AnnotationWindow.xaml` |

## 变更核对清单

调整布局时逐项确认：

- [ ] 改动前后控件归属编号未变（位置可动，编号不可动）
- [ ] 无编号被复用
- [ ] 删除的功能其编号已一并删除且不再分配
- [ ] 新增功能已按顺序续编
- [ ] 本文件已同步更新
